# Proyecto: Contribuciones CL

## Permisos
- Puedes leer y escribir libremente en esta carpeta
- Puedes ejecutar: pip install, python, node
- No necesitas confirmar creación de archivos .py, .html, .js

## Stack
- Python Flask + SQLite
- Frontend HTML con React embebido

## Diseño
- Usar shadcn/ui + Tailwind CSS
- Paleta: fondo #0a0a0a, texto #fafafa, acento #22c55e
- Tipografía: Inter para UI, JetBrains Mono para datos
- Bordes redondeados (radius-lg), sombras sutiles
- Todas las tablas con hover states y sorting
- Transiciones de 200ms en interacciones
